# Palestra (restyle 4/6) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Superserie trascinando le card durante l'allenamento, drop set dentro la serie, passo automatico per il peso, peso per lato chiaro e schermate della palestra riordinate.

**Architecture:** I calcoli puri (passo, drop, peso reale, volume, testo delle serie, operazioni sulla sessione con superserie) stanno in `public/js/services/gymLogic.js`, testati con node:test. Le schermate della palestra escono da `ui.js` e vanno in `public/js/views/gymUi.js`; `GymView.js` le collega. La sessione attiva resta in localStorage con il nuovo campo `superserie`; lo storico sul server non cambia schema (campi in più `superserie` sull'esercizio e `drop` sulla serie).

**Tech Stack:** JavaScript ES modules nel browser (Tailwind CDN, Chart.js), Node 24 + node:test per i test, Express/Mongo invariati.

**Spec:** `docs/superpowers/specs/2026-10-10-restyle-design.md`, sezione 4 (più le regole comuni 1–8).

## Global Constraints

- Pulsante principale nero (`bg-gray-900`), secondari bianchi con bordo, azzurro (`indigo`) solo per link, barre e selezioni, rosso solo per eliminare.
- Niente emoji: icone SVG da `components/icons.js`.
- Numeri: interi o un decimale con la virgola (`decimale()` di `components/format.js`), mai ",0".
- Passo peso: < 10 kg → 0,5; 10–30 kg → 1; > 30 kg → 2,5. Ripetizioni/minuti: 1.
- Peso reale = kg × `weightMultiplier` (1|2) + `barbellWeight`, solo se kg > 0.
- Superserie e drop decisi in allenamento: la scheda (`Routine`) non cambia schema.
- Import client con `?v=N` uniforme in tutta l'app (bump a fine lavoro).
- Mai il DB di produzione nei test: Mongo in memoria.

## Review Focus

- Trascinare una card su sé stessa o fuori da ogni card: non succede niente (nessuna superserie vuota o da 1).
- Esercizio di un blocco già superserie trascinato su un altro esercizio: il blocco vecchio perde quel membro e, se resta con uno solo, si scioglie.
- Superserie con numero di serie diverso (3 e 4): 4 giri, l'ultimo con un solo esercizio; "Salva giro" sull'ultimo non tocca l'altro.
- Peso scritto a mano con la virgola ("7,5") o vuoto: si salva 7,5 / 0, niente NaN nello storico.
- Sessione vecchia in localStorage senza `superserie` e serie vecchie senza `drop`: tutto funziona (campi opzionali).

```js
// public/js/services/gymLogic.js
const numero = (v) => parseFloat(String(v ?? '').replace(',', '.')) || 0;
const tondo = (v) => Math.round(v * 100) / 100;
const passo = (v) => v < 10 ? 0.5 : v < 30 ? 1 : 2.5;          // per salire
const passoSotto = (v) => v <= 10 ? 0.5 : v <= 30 ? 1 : 2.5;   // per scendere

export function passoPeso(valore, direzione) {
    const v = numero(valore);
    if (direzione === 'piu') { const p = passo(v); return tondo(Math.floor(v / p + 1e-9) * p + p); }
    const p = passoSotto(v);
    return Math.max(0, tondo(Math.ceil(v / p - 1e-9) * p - p));
}
export function pesoDrop(kg) { const v = numero(kg) * 0.8; const p = passo(v); return tondo(Math.floor(v / p + 1e-9) * p); }
export function pesoReale(kg, es = {}) { const v = numero(kg); return v > 0 ? tondo(v * (Number(es.weightMultiplier) || 1) + (Number(es.barbellWeight) || 0)) : 0; }
export function volumeSerie(set, es = {}) {
    if (es.type && es.type !== 'sala-pesi') return 0;
    return [set, ...(set.drop || [])].reduce((s, x) => s + pesoReale(x.kg, es) * numero(x.reps), 0);
}
const dec = (v) => String(tondo(numero(v))).replace('.', ',');
export function testoSerie(set, tipo) {
    if (tipo === 'cardio') return `${dec(set.reps)} min`;
    if (tipo === 'corpo-libero') return `${dec(set.reps)} rip`;
    return [set, ...(set.drop || [])].map(x => `${dec(x.kg)} × ${dec(x.reps)}`).join(' → ');
}
export function stima1RM(set, es = {}) {
    const kg = pesoReale(set.kg, es); const reps = numero(set.reps);
    if (!(kg > 0 && reps > 0)) return 0;
    return reps === 1 ? kg : kg * (36 / (37 - reps)); // Brzycki
}
```
